EventTicketing Platform

A full-stack ASP.NET Core 8 MVC web application integrated with MySQL and Stripe.

  • Core Architecture: ASP.NET Core MVC with Entity Framework Core & MySQL.
  • Security: Session authentication, role-based authorization, CSRF tokens, and rate limiting.
  • Ticketing: Stripe mock checkout with secure server-side QR generation.
  • Automated CI/CD: GitHub Actions running unit tests on every commit.
